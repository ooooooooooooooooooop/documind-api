# 在 FastAPI 中读取 .env 配置的方案

您已经安装了 `python-dotenv` 和 `pydantic`，这是处理环境变量的最佳组合。我们将使用 `pydantic-settings`（或 Pydantic 的 `BaseSettings`）来优雅地管理配置，而不是在代码中到处写 `os.getenv`。

### 计划步骤

1.  **创建 `.env` 文件**
    *   在项目根目录下创建一个 `.env` 文件，用于存放敏感配置（如 API 密钥、数据库 URL）。
    *   注意：该文件默认已被您的 `.gitignore` 忽略，这很好，可以防止密钥泄露。

2.  **创建 `app/config.py`**
    *   使用 Pydantic 定义一个 `Settings` 类。
    *   这个类会自动从环境变量或 `.env` 文件中读取对应的值，并进行类型检查。

3.  **在 `app/__init__.py` 中使用配置**
    *   导入 `settings` 对象，用它来替换硬编码的值（如果有）。

### 代码示例预览

**`.env`**:
```env
APP_NAME=DocuMind API
DEBUG_MODE=True
```

**`app/config.py`**:
```python
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    app_name: str = "DocuMind API"
    debug_mode: bool = False

    class Config:
        env_file = ".env"

settings = Settings()
```
